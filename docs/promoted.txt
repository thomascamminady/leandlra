# Catalogue modules that belong to the core library.
#
# One module name per line; `#` starts a comment. scripts/gen_root.sh adds these modules to
# LeanDLRA.lean, so `lake build LeanDLRA` builds them and the gate blocks on them.
# A module is listed here for one of two reasons (docs/STRUCTURE.md):
#   * a core module imports it (scripts/core.py check enforces that the core never imports a
#     module that is not core), or
#   * it has been promoted: its definitions are bridged to the core definitions and its main
#     theorems are stated in them.
